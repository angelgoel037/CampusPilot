# CampusPilot — Final Prototype

## Status

**Working hackathon proof-of-concept.**

## Demonstrated product loop

`Choose interests → receive ranked campus information → understand why it was recommended → add events to My Plan → detect schedule conflicts → explore the wider campus catalogue.`

## Product pillars

1. Personalized campus discovery
2. Important institutional information
3. Explainable recommendation
4. Personal event planning
5. Time-conflict detection
6. Cross-category exploration

## Demo data

The prototype ships with 40 curated CampusPilot items covering eight canonical categories.

## Scope deliberately excluded from the final MVP

- real authentication
- live Instagram/WhatsApp ingestion
- production database persistence
- paid AI APIs
- push notifications
- college ERP features

These are intentionally deferred so the hackathon prototype remains runnable without external services.
